# Stitch Web · 图片拼接小工具

浏览器里就能用的截图拼接工具（Web / Mobile Web），参考 [ekibun/Stitch](https://github.com/ekibun/Stitch)
与 [Subtitle Stitch](https://www.subtitlestitch.com/zh) 的思路实现。**纯前端运行，图片不上传，全部本地处理。**

## 功能

| 模式 | 用途 |
| --- | --- |
| **截图拼接** | 把多张滚动截图拼成一张长图 |
| **拼图** | 1–16 张图片套用网格布局做拼图 |
| **展示图** | 生成 App Store / Google Play 尺寸的展示图 |

### 1. 截图拼接

- **无缝裁剪**：自动计算相邻截图的交叉重叠区域并裁掉，直接拼成无痕长图（默认）。
- **过渡混合**：同样对齐，但在接缝处做渐变过渡，遮盖轻微色差 / 抗锯齿差异。
- **字幕堆叠**：影视字幕截图专用 —— 首张显示完整画面，之后每张只保留底部字幕条
  （默认 15% 高度），堆叠成字幕长图。可逐张切换「完整 / 字幕」并单独调整字幕条高度、
  上下裁切区域；在预览里点选图片后上下拖动即可直接拉长 / 缩短字幕条。
- **简单串联**：不做分析，直接依次排列（可设间距）。

辅助能力：

- **差值模式**：忽略跨图完全相同的静态区域（状态栏、贴顶横幅等），只用滚动内容对齐，
  避免重合内容把匹配带偏。
- **固定栏（高级）**：每张都相同、只需保留一次的贴顶 / 贴底区域（状态栏、导航栏），
  可一键自动检测。注意：*每张都变化的底部字幕请用「字幕堆叠」*。
- **分段偏移**：每一段的重叠量可手动微调，并给出匹配置信度提示。

### 2. 拼图

- 1–16 张自动套用网格 / 特色布局，可切换比例（1:1、4:5、9:16…）。
- 间距、外边距、圆角、背景色（支持透明）可调。
- 点选某一格后拖动可平移画面、滑块缩放；缩略图里点选两张即可交换位置。

### 3. 展示图

- 预设尺寸：iPhone 6.7/6.5/6.1/5.5、iPad 12.9、Google Play、社交卡片、方形。
- 单机 / 双机 / 三机模板，自动套上设备边框（含灵动岛）与投影。
- 标题、副标题、渐变背景与配色、设备大小 / 圆角 / 间距均可调。

### 导出

PNG / JPG / WebP，0.5× / 1× / 2× 倍率，质量可调，支持一键保存或复制到剪贴板。
超出浏览器画布上限时会自动降级并提示。

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产出静态站点到 dist/
npm run preview  # 本地预览构建产物
```

构建产物是纯静态文件（`base: './'`），可直接丢到 GitHub Pages / OSS / 任意 CDN。

## 算法说明

核心在 `src/core/`：

- **`gray.ts`** —— 把图片栅格化为灰度亮度数组。
- **`matching.ts`**
  - `estimateOffset`：寻找两张图沿滚动轴的平移量。做法是构建**盒式滤波图像金字塔**，
    在最粗层全范围搜索，再逐层在 ±3 像素窗口内细化到原生分辨率。
    盒式平均（而非点采样）能消除高频混叠，避免落入错误的局部极小值。
  - **最小重叠约束**：重叠过小的匹配容易「碰巧」吻合，因此默认要求至少 15% 重叠，
    否则按「无重叠」首尾相接处理。
  - **置信度**：在 1/4 分辨率上计算「峰比」——最优偏移的误差与圈外次优偏移的误差之比，
    用来判断匹配是否可信。
  - **差值模式**：按同坐标像素差给每个像素加权，跨图完全相同的区域权重为 0，
    从而忽略静态叠加内容。
  - `detectFixedBars`：找出在所有帧里都相同的顶部 / 底部行，判定为固定栏。
- **`stitch.ts`**
  - `analyzeStitch`：逐对计算偏移（先在降采样宽度上粗算，再到原生分辨率精修）。
  - `buildGeometry`：把参数翻译成一张画布上的绘制指令（源矩形 → 目标矩形），
    支持无缝裁剪 / 过渡混合 / 字幕堆叠 / 简单串联 / 固定栏。
  - `composeStitch` / `paintStitch`：把指令绘制到导出画布或实时预览。
- **`layouts.ts`** —— 1–16 张的网格与特色布局。
- **`showcase.ts`** —— 商店展示图的尺寸、背景、设备边框与排版。
- **`export.ts`** —— 格式 / 质量 / 倍率与浏览器画布上限处理。

已验证：无重叠裁剪的长图、固定栏长图、字幕堆叠、过渡混合，都能与参考合成结果逐像素一致。

## 目录结构

```
src/
├── core/            # 纯逻辑：灰度、匹配、拼接几何、布局、展示图、导出
├── components/      # 通用 UI（按钮、滑块、面板、缩略图栏、导出面板…）
├── modes/           # 三个模式：截图拼接 / 拼图 / 展示图
├── hooks/useAssets  # 图片加载、排序、释放
├── App.tsx          # 模式切换、粘贴导入、全局状态
└── styles.css       # 深色主题、移动端优先布局
```

## 说明

- 图片全部在本地内存中处理，不上传、不存储。
- 单次最多 16 张（可调整 `MAX_IMAGES`）。
- 支持点击 / 拖拽 / 粘贴（`⌘V`）导入图片。
